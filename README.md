# Self-Learning Skills & Tools

A personal collection of reusable Codex skills, tool notes, and workflows that support independent learning.

## Skills

### Adaptive Slide Tutor

`skills/adaptive-slide-tutor` turns Codex into a concise, adaptive tutor for slide decks, lecture notes, PDFs, equations, and technical concepts. It tracks understanding within the active conversation, corrects precise misconceptions, and explains concepts progressively.

To use it, copy the skill directory into your Codex skills directory and invoke `$adaptive-slide-tutor` with a slide deck or topic.
